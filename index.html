데이터 분석 학습용

문제에서 알고리즘까지,
한 장으로 연결해서 보기

“무엇을 알고 싶은가?”에서 시작해 분석 유형을 고르고, 각 알고리즘이 입력 → 전처리 → 학습 → 평가 → 해석으로 어떻게 흘러가는지 확인하는 개인 학습용 지도입니다.

0. 모든 분석의 공통 시작점

알고리즘은 시작점이 아니라 중간 도구입니다.

1. 어떤 문제인가?

아래 질문에서 가장 가까운 것을 고르면 됩니다.

📊 현재 데이터를 설명평균·분포·그룹 차이·관계가 궁금하다 → EDA / 기술통계 / 상관
🔢 숫자를 예측가격·매출·수요처럼 연속적인 값을 맞히고 싶다 → Regression
🏷️ 종류를 예측정상/사기, 이탈/유지처럼 범주를 맞히고 싶다 → Classification
🧩 그룹을 찾기정답 라벨 없이 비슷한 대상을 묶고 싶다 → Clustering
🗜️ 변수를 압축변수가 너무 많고 핵심 축을 찾고 싶다 → PCA
🚨 이상한 관측치 찾기정상 패턴에서 벗어난 데이터를 탐지 → Anomaly Detection
⏱️ 시간 흐름을 분석추세·계절성·미래 값을 알고 싶다 → Time Series
🧮 여러 지표를 하나로여러 변수로 위험도·점수·지수를 만들고 싶다 → Composite Index

2. 알고리즘별 내부 흐름

카드를 눌러 세부 흐름을 펼치세요. 각 카드의 “단계별 세부 로직 보기”를 누르면 그 단계에서 평균적으로 쓰이는 구체적인 기법까지 볼 수 있습니다.

📊

EDA / 기술통계

기초 · 데이터 이해
⌄
입력 원본 데이터
  • 원본 파일 로드(CSV/DB/API)
  • 데이터 사전(codebook)과 스키마 대조
행/열 · 타입 · 단위 확인
  • dtype 캐스팅(문자열→숫자/날짜 등)
  • 단위 통일(원/달러, m/km 등), 범주형 vs 연속형 구분
결측치 · 중복 · 이상치 확인
  • 결측 패턴 파악(MCAR/MAR/MNAR)
  • 중복 행 제거, IQR·Z-score로 극단값 스크리닝
평균 · 중앙값 · 표준편차 · 사분위수
  • 그룹별 describe(), 최빈값(범주형)
  • 왜도·첨도로 분포 치우침 확인
히스토그램 · 박스플롯 · 산점도 · 그룹 비교
  • 상관행렬 · 히트맵으로 변수 간 관계 확인
  • t-test · ANOVA로 그룹 간 차이 검정
결과 데이터 특성과 다음 분석 방향 결정
  • 발견한 이슈 정리, 가설 후보 목록화
  • 적합한 분석 기법 후보 좁히기
언제?

거의 모든 분석의 첫 단계.

주의

평균 하나만 보고 전체 분포를 판단하지 않는다.

📈

선형 회귀

회귀 · 숫자 예측 / 관계 설명
⌄
입력 X 독립변수 + y 연속형 목표값
  • 피처 · 타깃 정의, 데이터 타입 확인
결측·이상치·선형성·다중공선성 확인
  • 결측 대체(평균/중앙값/모델 기반)
  • VIF로 다중공선성 점검, 산점도로 선형성 확인
Train / Test 분리
  • hold-out split(예: 8:2), 필요시 K-fold CV
오차가 작아지도록 회귀계수 β 추정
  • OLS(최소제곱법), 정규방정식 또는 경사하강법
  • 과적합 방지 시 Ridge(L2) · Lasso(L1) 정규화
MAE · RMSE · R² + 잔차 진단
  • Q-Q plot으로 잔차 정규성 확인
  • Durbin-Watson으로 자기상관 점검
결과 예측값 + 변수별 계수 해석
  • 표준화 계수로 변수별 영향력 비교
  • 계수 신뢰구간 확인
강점

해석이 쉽고 좋은 baseline이 된다.

주의

계수가 곧 인과효과라는 뜻은 아니다.

🎯

로지스틱 회귀

분류 · 확률 기반
⌄
입력 X + 범주형 y
  • 피처 · 이진/다중 클래스 타깃 정의
전처리 · 스케일링 · 클래스 비율 확인
  • 표준화(StandardScaler), 범주형 원-핫 인코딩
  • 클래스 불균형 시 오버/언더샘플링(SMOTE 등)
Train / Test 분리
  • stratified split으로 클래스 비율 유지
각 클래스에 속할 확률 추정
  • 시그모이드 함수로 로짓을 확률로 변환
  • 최대우도추정(MLE)으로 계수 학습
Threshold로 클래스 결정
  • 기본 0.5, 비용/목적에 따라 threshold 조정
  • ROC 곡선에서 최적 지점 탐색
Precision · Recall · F1 · ROC-AUC 평가
  • 혼동행렬 분석
  • 불균형 데이터는 PR curve로 보완
결과 클래스 + 예측 확률
강점

확률과 계수 해석이 비교적 쉽다.

주의

불균형 데이터에서는 Accuracy만 보면 위험하다.

🌳

Decision Tree

분류/회귀 · 규칙 기반
⌄
입력 X + y
데이터를 가장 잘 나누는 조건 탐색
  • 분류: Gini 불순도 · 정보이득(Entropy)
  • 회귀: 분할 후 MSE 감소량 기준
조건에 따라 노드를 반복 분할
  • 재귀적 이진 분할, 각 노드에서 최적 피처·임계값 탐색
정지 조건 / 가지치기로 복잡도 제어
  • max_depth, min_samples_leaf 등 하이퍼파라미터
  • cost-complexity pruning(사후 가지치기)
분류 또는 수치 예측
  • 리프 노드의 다수 클래스(분류) 또는 평균값(회귀) 반환
평가 Test/CV 성능 + 트리 구조 확인
  • 트리 시각화로 분할 기준 검토
  • feature importance 확인
강점

비선형 관계와 상호작용을 표현하기 쉽다.

주의

깊은 단일 트리는 과적합되기 쉽다.

🌲

Random Forest

분류/회귀 · Bagging
⌄
입력 X + y
여러 bootstrap 표본 생성
  • 복원추출로 N개 샘플셋 생성
  • 트리마다 피처 서브셋도 무작위 선택(max_features)
각 표본에서 서로 다른 Decision Tree 학습
  • 가지치기 없이 깊게 성장시켜 트리 간 상관 최소화
분류: 다수결 / 회귀: 평균
  • 모든 트리의 예측을 집계(aggregation)
Test/CV 평가 + 변수 중요도 참고
  • OOB(out-of-bag) 오차로 별도 검증셋 없이 성능 추정
결과 단일 트리보다 안정적인 예측
강점

복잡한 정형 데이터에서 안정적인 baseline.

주의

변수 중요도는 인과관계가 아니다.

⚡

Gradient Boosting

XGBoost · LightGBM · CatBoost
⌄
입력 X + y
첫 약한 모델 학습
  • 보통 얕은 트리(stump)로 시작, 초기 예측은 평균/로그오즈
현재 모델의 오차/잔차 계산
  • 손실함수의 gradient(음의 기울기) 계산
오차를 줄이는 다음 모델 추가
  • 잔차를 타깃으로 새 트리 학습
  • learning rate로 기여도 조절(shrinkage)
이 과정을 순차적으로 반복
  • n_estimators만큼 반복, 매번 이전 오차를 보정
CV · Early stopping · 튜닝
  • validation loss로 조기 종료
  • learning_rate · max_depth · subsample 그리드 탐색
결과 여러 약한 모델을 합친 강한 예측기
강점

정형 데이터 예측에서 매우 강력하다.

주의

튜닝과 데이터 누수 관리가 중요하다.

📍

KNN

분류/회귀 · 거리 기반
⌄
입력 X + y
변수 스케일 맞추기
  • 표준화 필수(거리 기반이라 스케일 차이에 민감)
  • 범주형은 인코딩 후 거리정의 재검토
새 관측치와 모든 학습점의 거리 계산
  • 유클리드 · 맨해튼 · 코사인 거리 중 선택
가장 가까운 K개 선택
  • 작은 K: 과적합 경향 / 큰 K: 과소적합 경향
분류: 투표 / 회귀: 평균
  • 거리 가중 투표(weighted KNN)도 가능
평가 K값을 CV로 선택
  • 여러 K에 대한 CV 오차 곡선에서 최적 K 탐색
강점

직관적이고 별도 복잡한 학습 과정이 없다.

주의

스케일과 차원 수에 매우 민감하다.

🧩

K-Means

군집 · 비지도학습
⌄
입력 정답 없는 X
스케일링 + K개 중심 초기화
  • 표준화 필수
  • K-means++로 초기 중심을 퍼뜨려 수렴 안정화
각 점을 가장 가까운 중심에 배정
  • 유클리드 거리 기준 클러스터 라벨 할당
각 그룹 평균으로 중심 이동
  • 클러스터별 centroid 재계산
배정과 이동을 수렴할 때까지 반복
  • 중심 이동이 임계값 이하이거나 max_iter 도달 시 종료
Elbow / Silhouette로 군집 품질 확인
  • WCSS(군집 내 분산)가 꺾이는 지점 탐색
  • Silhouette score로 군집 분리도 확인
결과 K개의 데이터 그룹
강점

대규모 데이터에도 비교적 빠르고 직관적이다.

주의

K를 정해야 하며 구형 군집 가정에 가깝다.

🌌

DBSCAN

군집 · 밀도 기반
⌄
입력 정답 없는 X
거리 스케일 확인 / 표준화
eps 반경 내 이웃 개수 계산
  • k-distance plot으로 적정 eps 추정
충분히 밀집된 점에서 군집 확장
  • core point(min_samples 이상 이웃) 기준 밀도 연결 확장
어느 군집에도 속하지 않으면 Noise
  • border point와 noise point 구분
결과 임의 모양 군집 + 이상점
강점

K를 미리 정하지 않고 복잡한 모양을 찾는다.

주의

밀도가 크게 다른 군집에는 설정이 어렵다.

🗜️

PCA

차원축소 · 정보 압축
⌄
입력 여러 수치 변수 X
일반적으로 중심화/표준화
  • 평균 0으로 센터링
  • 스케일 차이가 크면 표준화(분산 기준 왜곡 방지)
데이터 분산이 큰 방향 탐색
  • 공분산 행렬 계산 후 고유값 분해 또는 SVD
서로 직교하는 주성분 PC 생성
  • 고유값이 큰 순서대로 PC 정렬
  • 각 PC는 원 변수들의 선형결합
Explained Variance 확인
  • 누적 설명분산 그래프(scree plot)로 유지할 PC 개수 결정
필요한 PC만 선택해 데이터 변환
  • 선택한 PC로 원 데이터를 투영(projection)
결과 적은 차원의 새로운 변수
강점

상관된 많은 변수를 압축할 수 있다.

주의

PC가 원래 변수보다 해석하기 어려울 수 있다.

🚨

Isolation Forest

이상탐지
⌄
입력 주로 정상 관측치가 많은 X
무작위 변수와 분할점으로 여러 트리 생성
  • 각 iTree마다 무작위 피처·임계값으로 재귀 분할
각 관측치가 격리되기까지 필요한 분할 수 측정
  • 평균 경로 길이(path length) 계산
빠르게 격리되는 관측치에 높은 이상점수
  • 경로 길이가 짧을수록 이상 스코어 상승
임계값/contamination으로 이상치 지정
  • contamination 비율 지정 또는 score threshold 직접 설정
결과 정상/이상 + anomaly score
강점

고차원 데이터에도 적용 가능하다.

주의

‘드물다’와 ‘문제다’는 같은 뜻이 아니다.

⏱️

시계열 분석 / ARIMA 계열

시간 순서 · Forecasting
⌄
입력 시간순 데이터
추세 · 계절성 · 결측 · 이상치 확인
  • 시계열 분해(STL 등)로 추세/계절성 분리
  • 결측 보간(선형/시간가중)
시간순 Train / Validation 분할
  • 무작위 셔플 금지, rolling/expanding window 분할
정상성/차분/자기상관 구조 확인
  • ADF 검정으로 정상성 확인, 필요시 차분(differencing)
  • ACF/PACF로 (p, q) 후보 파악
ARIMA/SARIMA 등 모델 학습
  • (p,d,q) 또는 계절성 (P,D,Q,m) 파라미터 추정
  • MLE로 계수 적합
미래 구간 예측 + MAE/RMSE 등 평가
  • walk-forward validation
  • 예측구간(prediction interval) 계산
결과 미래값 + 예측 불확실성
강점

시간 의존성과 추세를 명시적으로 다룬다.

주의

랜덤 셔플 분할을 하면 미래 정보 누수가 생길 수 있다.

🧮

Composite Index

복합지수 · 위험/평가지수 구축
⌄
질문 무엇을 하나의 지수로 표현할 것인가?
이론적 틀 → 변수 선정
  • 문헌 · 전문가 검토로 하위지표(sub-indicator) 후보 선정
데이터 단위 · 방향 · 공간/시간 수준 확인
  • 역방향 지표는 부호 반전
  • 지리적/시간적 집계 수준 통일
결측치 처리 + Raw/Z-score/Min-Max/Percentile 등 정규화 결정
  • 정규화 방식별 결과 비교
  • 결측은 보간 또는 해당 하위지표 제외
가중치 결정 → Weighted Sum / Geometric Mean 등 집계
  • 동일가중 / PCA 기반 가중치 / 전문가 델파이 기법 등
