문제에서 알고리즘까지,
한 장으로 연결해서 보기

“무엇을 알고 싶은가?”에서 시작해 분석 유형을 고르고, 각 알고리즘이 입력 → 전처리 → 학습 → 평가 → 해석으로 어떻게 흘러가는지 확인하는 개인 학습용 지도입니다.

0. 모든 분석의 공통 시작점

알고리즘은 시작점이 아니라 중간 도구입니다.

→
② 데이터 확보답에 필요한 관측치는?
→
③ 데이터 이해행·열·단위·표본·분포
→
④ EDA/전처리결측·이상치·관계 확인
→
⑤ 방법 선택질문에 맞는 알고리즘
→
⑥ 검증/해석믿을 수 있는 결과인가?

1. 어떤 문제인가?

아래 질문에서 가장 가까운 것을 고르면 됩니다.

📊 현재 데이터를 설명평균·분포·그룹 차이·관계가 궁금하다 → EDA / 기술통계 / 상관
🔢 숫자를 예측가격·매출·수요처럼 연속적인 값을 맞히고 싶다 → Regression
🏷️ 종류를 예측정상/사기, 이탈/유지처럼 범주를 맞히고 싶다 → Classification
🧩 그룹을 찾기정답 라벨 없이 비슷한 대상을 묶고 싶다 → Clustering
🗜️ 변수를 압축변수가 너무 많고 핵심 축을 찾고 싶다 → PCA
🚨 이상한 관측치 찾기정상 패턴에서 벗어난 데이터를 탐지 → Anomaly Detection
⏱️ 시간 흐름을 분석추세·계절성·미래 값을 알고 싶다 → Time Series
🧮 여러 지표를 하나로여러 변수로 위험도·점수·지수를 만들고 싶다 → Composite Index

2. 알고리즘별 내부 흐름

카드를 눌러 세부 흐름을 펼치세요. 검색창으로 바로 찾을 수도 있습니다.

📊

EDA / 기술통계

기초 · 데이터 이해
⌄
입력 원본 데이터
행/열 · 타입 · 단위 확인
결측치 · 중복 · 이상치 확인
평균 · 중앙값 · 표준편차 · 사분위수
히스토그램 · 박스플롯 · 산점도 · 그룹 비교
결과 데이터 특성과 다음 분석 방향 결정
언제?

거의 모든 분석의 첫 단계.

주의

평균 하나만 보고 전체 분포를 판단하지 않는다.

📈

선형 회귀

회귀 · 숫자 예측 / 관계 설명
⌄
입력 X 독립변수 + y 연속형 목표값
결측·이상치·선형성·다중공선성 확인
Train / Test 분리
오차가 작아지도록 회귀계수 β 추정
MAE · RMSE · R² + 잔차 진단
결과 예측값 + 변수별 계수 해석
강점

해석이 쉽고 좋은 baseline이 된다.

주의

계수가 곧 인과효과라는 뜻은 아니다.

🎯

로지스틱 회귀

분류 · 확률 기반
⌄
입력 X + 범주형 y
전처리 · 스케일링 · 클래스 비율 확인
Train / Test 분리
각 클래스에 속할 확률 추정
Threshold로 클래스 결정
Precision · Recall · F1 · ROC-AUC 평가
결과 클래스 + 예측 확률
강점

확률과 계수 해석이 비교적 쉽다.

주의

불균형 데이터에서는 Accuracy만 보면 위험하다.

🌳

Decision Tree

분류/회귀 · 규칙 기반
⌄
입력 X + y
데이터를 가장 잘 나누는 조건 탐색
조건에 따라 노드를 반복 분할
정지 조건 / 가지치기로 복잡도 제어
분류 또는 수치 예측
평가 Test/CV 성능 + 트리 구조 확인
강점

비선형 관계와 상호작용을 표현하기 쉽다.

주의

깊은 단일 트리는 과적합되기 쉽다.

🌲

Random Forest

분류/회귀 · Bagging
⌄
입력 X + y
여러 bootstrap 표본 생성
각 표본에서 서로 다른 Decision Tree 학습
분류: 다수결 / 회귀: 평균
Test/CV 평가 + 변수 중요도 참고
결과 단일 트리보다 안정적인 예측
강점

복잡한 정형 데이터에서 안정적인 baseline.

주의

변수 중요도는 인과관계가 아니다.

⚡

Gradient Boosting

XGBoost · LightGBM · CatBoost
⌄
입력 X + y
첫 약한 모델 학습
현재 모델의 오차/잔차 계산
오차를 줄이는 다음 모델 추가
이 과정을 순차적으로 반복
CV · Early stopping · 튜닝
결과 여러 약한 모델을 합친 강한 예측기
강점

정형 데이터 예측에서 매우 강력하다.

주의

튜닝과 데이터 누수 관리가 중요하다.

📍

KNN

분류/회귀 · 거리 기반
⌄
입력 X + y
변수 스케일 맞추기
새 관측치와 모든 학습점의 거리 계산
가장 가까운 K개 선택
분류: 투표 / 회귀: 평균
평가 K값을 CV로 선택
강점

직관적이고 별도 복잡한 학습 과정이 없다.

주의

스케일과 차원 수에 매우 민감하다.

🧩

K-Means

군집 · 비지도학습
⌄
입력 정답 없는 X
스케일링 + K개 중심 초기화
각 점을 가장 가까운 중심에 배정
각 그룹 평균으로 중심 이동
배정과 이동을 수렴할 때까지 반복
Elbow / Silhouette로 군집 품질 확인
결과 K개의 데이터 그룹
강점

대규모 데이터에도 비교적 빠르고 직관적이다.

주의

K를 정해야 하며 구형 군집 가정에 가깝다.

🌌

DBSCAN

군집 · 밀도 기반
⌄
입력 정답 없는 X
거리 스케일 확인 / 표준화
eps 반경 내 이웃 개수 계산
충분히 밀집된 점에서 군집 확장
어느 군집에도 속하지 않으면 Noise
결과 임의 모양 군집 + 이상점
강점

K를 미리 정하지 않고 복잡한 모양을 찾는다.

주의

밀도가 크게 다른 군집에는 설정이 어렵다.

🗜️

PCA

차원축소 · 정보 압축
⌄
입력 여러 수치 변수 X
일반적으로 중심화/표준화
데이터 분산이 큰 방향 탐색
서로 직교하는 주성분 PC 생성
Explained Variance 확인
필요한 PC만 선택해 데이터 변환
결과 적은 차원의 새로운 변수
강점

상관된 많은 변수를 압축할 수 있다.

주의

PC가 원래 변수보다 해석하기 어려울 수 있다.

🚨

Isolation Forest

이상탐지
⌄
입력 주로 정상 관측치가 많은 X
무작위 변수와 분할점으로 여러 트리 생성
각 관측치가 격리되기까지 필요한 분할 수 측정
빠르게 격리되는 관측치에 높은 이상점수
임계값/contamination으로 이상치 지정
결과 정상/이상 + anomaly score
강점

고차원 데이터에도 적용 가능하다.

주의

‘드물다’와 ‘문제다’는 같은 뜻이 아니다.

⏱️

시계열 분석 / ARIMA 계열

시간 순서 · Forecasting
⌄
입력 시간순 데이터
추세 · 계절성 · 결측 · 이상치 확인
시간순 Train / Validation 분할
정상성/차분/자기상관 구조 확인
ARIMA/SARIMA 등 모델 학습
미래 구간 예측 + MAE/RMSE 등 평가
결과 미래값 + 예측 불확실성
강점

시간 의존성과 추세를 명시적으로 다룬다.

주의

랜덤 셔플 분할을 하면 미래 정보 누수가 생길 수 있다.

🧮

Composite Index

복합지수 · 위험/평가지수 구축
⌄
질문 무엇을 하나의 지수로 표현할 것인가?
이론적 틀 → 변수 선정
데이터 단위 · 방향 · 공간/시간 수준 확인
결측치 처리 + Raw/Z-score/Min-Max/Percentile 등 정규화 결정
가중치 결정 → Weighted Sum / Geometric Mean 등 집계
정규화·가중치·변수 선택을 바꾸는 민감도 분석
결과 지수 + 순위 + 불확실성/한계
핵심

‘계산법’보다 변수와 가중치의 이론적 근거가 중요하다.

주의

정규화 선택 때문에 순위가 뒤집히는지 반드시 확인한다.

3. 빠른 비교표

목적대표 방법목표값 y스케일 영향핵심 평가
데이터 이해EDA / 기술통계없어도 됨방법에 따라 다름분포·품질·해석
숫자 예측Linear / RF / Boosting연속형모델별 상이MAE·RMSE·R²
범주 예측Logistic / Tree / RF / Boosting범주형모델별 상이Precision·Recall·F1·AUC
그룹 발견K-Means / DBSCAN없음대체로 중요Silhouette + 해석 가능성
차원축소PCA없음중요Explained Variance
이상 탐지IQR / Isolation Forest선택적방법별 상이실제 이상 사례 검증
시간 예측ARIMA / SARIMA 등시간순 값방법별 상이시간순 검증 MAE/RMSE
하나의 지수Composite Index보통 없음매우 중요민감도·강건성·해석
학습할 때 기억할 문장
“어떤 알고리즘이 제일 좋은가?”보다 먼저 “내 질문은 무엇이고, 이 알고리즘의 가정이 내 데이터에 맞는가?”를 묻는다.
